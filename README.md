## Overview

This course provides a step-by-step guide to building an MVC web application using the **Laravel 13** framework and the **PHP 8.4** language. HTML pages are generated by the server using **Blade** views, without a browser-side JavaScript framework.

It adapts the course [Step-by-Step Introduction to the [Flask](https://stahe.github.io/en-flask-sept-2026/) Web Framework], itself based on the [Spring MVC](https://stahe.github.io/springmvc-sept-2026/) courses, [ASP.NET Core MVC](https://stahe.github.io/aspnetcoremvc-sept-2026/), and [NestJS](https://stahe.github.io/nestjs-html-sept-2026/). The examples have the same numbers and cover the same topics: you can compare the frameworks example by example.

## Contents

| Chapter | Topics | Examples |
|---|---|---|

| The View and Its Template | Blade, template, components, forms, validation, Post/Redirect/Get, CSRF protection | 13–21 |

| Data Scopes | Request, session, cache, cookies | 23 |
| The Request Lifecycle | middleware, parameter binding, exception handlers | 24 |
| Authentication and Authorization | JWT in a cookie, guards, roles, CAPTCHA, rate limiting | 25–27 |
| Layered Architecture | web / business logic / DAO with Eloquent and MySQL | 28 |
| Case Study | **RdvMedecins**, a medical appointment scheduling application, explained file by file | - |

The `rdvmedecins2-laravel` case study manages three roles (administrator, doctors, patients): calendars, reservations, doctor and client management, CAPTCHA-protected account creation, and a French/English interface. It uses the same `dbrdvmedecins2` database as the other versions of the application.

## Prerequisites

- PHP 8.4 or newer (extensions `intl`, `mbstring`, `openssl`, `pdo_mysql`);
- Composer 2;
- MySQL 8 or MariaDB (Laragon on Windows);
- Visual Studio Code with the PHP Intelense and Laravel extensions;
- curl.

The code is available for download from the course website. The `vendor` folders are not included there: `composer install` creates them, one in the `exemples` folder and one in the `rdvmedecins2-laravel` folder.
